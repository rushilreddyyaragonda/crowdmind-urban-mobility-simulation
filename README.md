# CrowdMind — Urban Mobility Simulation

Interactive research laboratory for exploring how individual movement decisions create city-scale congestion and network failures.

## Analysis

- **Core experience:** city designer, scenario library, simulation lab, route and agent inspectors, disruption controls, results observatory, and research notebook.
- **Technical approach:** React + TypeScript + Vite, seeded simulation state, graph/network rendering, route inspection, persistence, and scenario-driven experiments.
- **Portfolio value:** demonstrates systems thinking, simulation design, data visualization, and an ability to make complex emergent behavior explorable.
- **Current health:** production build and TypeScript check pass. ESLint reports existing unused imports/variables and a few hook/type-quality issues for follow-up.

## Run locally

```bash
npm install
npm run dev
```
